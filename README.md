## 🎯 Các chủ đề trọng tâm

- ✅ Java Core (JVM, Memory, Collection, Concurrency)
- ✅ Spring Boot (IoC, Bean, AOP, Auto Configuration)
- ✅ Transaction (ACID, Propagation, Isolation, Locking)
- ✅ Database (Index, Execution Plan, Partition, N+1)
- ✅ System Design (Chuyển tiền, Idempotency, Outbox Pattern)
- ✅ Microservice (Saga, Circuit Breaker, Service Communication)
- ✅ Message Queue (RabbitMQ, Kafka, DLQ, Idempotent Consumer)
- ✅ Redis (Cache Pattern, Distributed Lock, Cluster)
- ✅ Security (JWT, OAuth2, SQL Injection, XSS, CSRF, Replay Attack)
- ✅ Leadership (Team Management, Code Review, Conflict Resolution)
- ✅ Production Incident (Troubleshooting, RCA, Monitoring)

## 💡 Lưu ý quan trọng

> Một Tech Lead không chỉ cần biết câu trả lời đúng, mà cần thể hiện:
> - **Tư duy phân tích** (không đoán, mà đo)
> - **Trade-off** (không có giải pháp hoàn hảo)
> - **Kinh nghiệm thực chiến** (đã từng xử lý sự cố)
> - **Khả năng dẫn dắt** (giúp team phát triển)
